# Notation decisions — Noether 1926, *Ableitung der Elementarteilertheorie aus der Gruppentheorie*

Work-spanning rendering decisions for this transcription. The work is a single printed page
(Jahresbericht der DMV 34, Abteilung 2, p. 104), so no two batches had to agree with each other
here; the entries exist because each records a reading of the scan that a reviewer would otherwise
have to make again from the image. Each entry is the decision, why it was made, and the
alternatives that are **not** to be used.

## Scope of the item

- **Only Noether's own paragraph is this work.** Printed p. 104 is a page of the Göttingen
  Mathematical Society's collective meeting report and carries six abstracts by six speakers.
  Everything before "Die Elementarteilertheorie gibt bekanntlich…" and everything from
  "--- 3. Februar 1925." onward belongs to other speakers or to the report. Never extend the
  transcription to the rest of the page on the grounds that it is on the same page and equally
  public domain — those are different works by different authors.
- **The report's separators are apparatus and are dropped; Noether's own dashes are kept.** The
  em-dash before "E. Noether:" and the one before "3. Februar 1925." separate speakers and are not
  transcribed. The pair around "z.\ B. Bettische und Torsionszahlen in der Topologie" is
  parenthetical punctuation inside her last sentence and is transcribed as `---` (R17). Do not
  treat all four alike.

## Symbols

- **The normal basis is `$(e_1 y_1, e_2 y_2, \ldots, e_r y_r)$`** — subscripts 1, 2 and r, a
  single pair of parentheses, commas between terms. Read at magnification from the source scan;
  the period-sized subscript numerals of this face are the one place on the page where the
  1568px-capped image is not enough. Never `e_i y_i`, never `e_1y_1` with the letters closed up,
  and never an added `\cdot` between $e$ and $y$ — the print's small gap there is kerning, not an
  operator.
- **The ellipsis is `\ldots`.** The print sets three baseline dots followed by a comma
  (". . .,"). Write `\ldots,` — never literal spaced dots, never `\cdots`, never `\dots`.
- **Bare `$e$` stays math, in both of its running-text occurrences** — "wo jedes $e$ durch das
  folgende teilbar ist" and "die $e$ sind dadurch". The print sets an italic *e* matching the one
  in the normal basis, against upright roman prose. Never `\emph{e}`, never a bare roman e.
- **No Fraktur, no Greek, no displayed math occurs in this item.** Nothing is `\mathfrak{}`, and
  there is no `\[ … \]` block. Recorded so a later pass does not introduce one by promoting the
  inline normal basis to a display: its position inside the sentence is the print's.

## Orthography

- **This is an Antiqua print that sets a real eszett, so `ß` is transcribed as `ß`** — "größter"
  carries the only one in this item, and "aufs" correctly has none. ("daß" does not occur in
  Noether's paragraph; it is set twice elsewhere on printed p. 104, in other speakers'
  abstracts, so do not read this entry as a claim about the page.) There is no long-ſ and no
  `ſs` ligature anywhere on the page, so R19's ligature conversion never applies here; the `ß`
  in "größter" is a `ß` in the metal, read directly.
- **Umlauts are literal `ä ö ü Ü`** (R18): "für", "üblichen", "Übergang", "größter",
  "Zurückgehen". Never `\"u`, never `\ss`.
- **`z.\ B.` carries a LaTeX control space after the first dot** (R17), matching the print's
  spaced "z. B.". Never `z.B.`, never `z. B.` with a plain space, which TeX would set as
  end-of-sentence spacing.

## Readings deliberately left as printed

- **"als direkte Summe größter zyklischer" is elliptical in the print** — the noun ("Gruppen") is
  not set. This is the author's own compression in a terse abstract, not a compositor's drop, so
  it is neither completed nor given an `\ednote` (R4 covers misprints, and this is not one).
  Recorded so a reviewer does not read it as a transcription slip.
- **"Bettische" is the print's adjective from Betti** and is kept as printed; it is not
  letterspaced, and it is not to be normalized to "Bettische Zahlen" or expanded.
